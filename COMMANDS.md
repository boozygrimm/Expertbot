# Команды и обращения ExpertBot

Справочник относится к текущему коду, а не подтверждает настройки конкретного
сервера. В группах доступ должен быть одобрен владельцем бота; доступность
функций зависит от `/panel`, прав Telegram, состояния MongoDB и провайдеров.
[README](README.md) описывает хранение истории, квоты и развёртывание.

Telegram-меню показывает только часть команд: его списки по ЛС, ЛС владельца и
группам находятся в [bot_commands.py](bot_commands.py). Команда может работать,
даже если её нет в меню. Telegram не принимает кириллицу в `setMyCommands`;
кириллические алиасы обрабатываются ботом как введённый текст, но интерфейс
клиента может не предлагать их как команды.

## Пользователям

| Команда или обращение | Назначение и условия |
| --- | --- |
| `/start`, `/help`, `/хелп`, `/хэлп`, `/справка`, `/экс помощь` | Краткая справка; `/help@имя_бота` также поддерживается. Для Штаба используется отдельная глубокая ссылка `/start alcbase`, которую выдаёт `/base` в группе. |
| `/support` | Связь с владельцем. |
| `Экс, вопрос`, `Эксперт, вопрос` | Диалог, поиск, погода, музыка, рисунки, игры и другие действия; запрос можно отправить текстом, голосовым или кружком. Для голосовых нужен модуль «Голосовые». |
| Ответ на сообщение самого бота | Текст, голосовое или кружок могут продолжить разговор без слова «Экс»; голосовое/кружок сначала распознаются. Ответ на чужое сообщение сам по себе не является обращением. |
| Фото с подписью `Экс, что на фото?` или ответ на фото с вопросом `Экс, ...` | Прямое распознавание фото. При ошибке бот сообщает, что не смог его рассмотреть, а не придумывает содержание. |
| `/bender вопрос`, `Экс, кружок вопрос` | Прямой запрос видеокружка в группе при включённых «Кружках Бендера» и настроенной студии. Текст запроса можно не указывать. |
| `/img запрос`, `/pic запрос`, `/рис запрос` | Генерация изображения. Две бесплатные успешные отправки в день на пользователя и чат, затем 250 игровых очков; день по МСК. Нужен модуль «Картинки» и доступный провайдер. |
| `/song название` | Поиск музыки и выбор трека. Нужен модуль «Музыка». |
| `/voice`, `/voice on`, `/voice off` | Статус и управление **публикацией** расшифровок. В группе статус доступен участникам, а переключение — администраторам и владельцу бота; в ЛС — пользователю. При `/voice off` модуль «Голосовые» продолжает фоновое распознавание и сохранение текста. Команда доступна при включённом модуле. |
| `/gossip [число]`, `/сплетни [число]`, `/вещай [число]`, `/выбор [число]` | Сводка по последним сообщениям чата: по умолчанию 50, диапазон 1–3000. Текстовые `сплетни`, `вещай`, `выбор` тоже поддерживаются. Один эксперт отвечает сразу; при нескольких показывается выбор. Сплетни независимы от панели «Отчёты (резерв)» и расписания суточного отчёта. |
| `/pole`, `/vis` (алиас `/виселица`) | Поле чудес и Виселица. |
| `/anachronism [ставка]`, `/анахронизм [ставка]`, `/ставка [ставка]` | Анахронизм; по умолчанию ставка 1000, необходимы очки в этом чате. |
| `/stop`, `/хватит` | Остановить активную партию Поля чудес или Виселицы. |
| `/topgame`, `/топигр`, `/очки` | Общий рейтинг игроков чата. |
| `/топполе [дни]` | Статистика Поля чудес, необязательный период в днях. |
| `/base`, `/база` | Штаб алхимии в ЛС; в группе бот выдаёт ссылку в ЛС. |
| `/pohod`, `/поход`, `/добыча` | Меню экспедиции алхимика. |
| `/грабить` | Рейд: нужен собранный и заряженный отряд. Ответом на игрока — нападение на него; без цели или при ответе боту — предложение PvE. |
| `Экс, шпора название` | Рецепт алхимии через Экса; после успешного запроса действует пятиминутная пауза. `/шпора` — отдельная команда только для владельца. |
| `/соцсправка`, `/ник имя`, `/пол м`, `/пол ж` | Справка Social RP и настройки профиля в чате. Само RP запускается текстом-ответом на другого участника, например `обнять`; модуль должен быть включён. |

Обычный ответ в группе может предлагать **⭕ Кружок / 🎙 Голос / 💬 Текст**
в зависимости от настроек панели. Выбирает автор запроса; выбор истекает через
3 минуты, затем бот пытается удалить меню. Если доступны только текстовые
ответы, меню не показывается. Включённый «Автоответ голосом» обходит выбор
для обычных обращений входящим голосовым, но не кружком. Специальные действия
(музыка, поиск, изображения, игры и т. д.) выполняются своим путём.

## Администраторам группы

| Команда | Назначение |
| --- | --- |
| `/panel`, `/панель` | Панель модулей непосредственно в группе; менять настройки могут администраторы группы или владелец бота. В личке владельца открывает панель новостей. |
| `/социал`, `/социал18` | Включить или выключить обычное / взрослое RP; права администратора группы проверяются обработчиком. |
| `/set_daily ЧЧ:ММ`, `/cron ЧЧ:ММ` | Задать ежедневный отчёт в группе по МСК. При выключенном модуле суточного отчёта используйте `/panel`: панель запрашивает время при включении. |
| `/stop_daily` | Отключить ежедневный отчёт группы. |
| `/vest` | Скрытый ручной отчёт за сутки для администратора группы; точное текстовое совпадение `/vest`. |

`/voice on/off` управляет общей настройкой публикации группы и требует прав
администратора или владельца бота. Отключение модуля «Голосовые» в панели
останавливает новые фоновые распознавания; уже запущенные могут завершиться.
Переключатель «Отчёты (резерв)» сохранён для совместимости со старыми
настройками и не управляет сплетнями. «Суточный отчёт» настраивается отдельно.
Обращение к Эксу с просьбой о сплетнях по-прежнему требует включённого «Эксперта»;
для голосового или кружка нужен также модуль «Голосовые».

## Владельцу бота и диагностике

Команды ниже не предназначены для обычных игроков. Если не указано иное,
обработчики проверяют `ADMIN_ID`; это не то же самое, что администратор группы.
Не передавайте секреты бота, ключи и содержимое `.env` в чат.

| Команда | Назначение / риск |
| --- | --- |
| `/panel` в личке | Панель новостей: сбор, его состояние, просмотр и выбор новостей. Без дополнительных переменных Render. Подробнее: [новостные черновики](news_prototype/OWNER_DRAFTS.md). |
| `/news_daily_status`, `/news_collected` | Прежние команды состояния сбора и просмотра новостей, сохранены для совместимости. |
| `/chats` | Управление авторизацией чатов. |
| `/cron`, `/set_daily` в ЛС | Меню настройки суточных отчётов для групп. |
| `/image_probe` | Только ЛС владельца: реальные запросы к Cloudflare и OVHcloud; расходуются квоты, игровые попытки и очки не списываются. |
| `/search_image_probe [запрос]` | Только ЛС владельца: реальная проверка поиска с изображением, расходует квоту поиска. |
| `/regen_quests` | Принудительно перегенерировать квесты **всем игрокам**. |
| `/lore_help`, `/справкалор`; `/lore_edit`, `/lore_edit seed`, `/cancel_lore` | Справка и редактор наследия; `seed` обновляет стартовые наследия, `cancel_lore` отменяет ввод. |
| `/шпора [название]` | Точный рецепт; без названия полный список доступен только в ЛС владельца. |
| `/promo [s\|m\|l\|xl]`, `/промо [s\|m\|l\|xl]` | Выдать промо-пак алхимии игроку через reply; по умолчанию `s`. Изменяет инвентарь. |
| `/clear_inv` | Очистить инвентарь игрока через reply. **Необратимое изменение данных.** |
| `/alc_reset ID` | Удалить профиль алхимика по ID. **Необратимое изменение данных.** |
| `/промокод сумма` | Начислить или списать игровые очки через reply; также поддерживается поиск по имени. В этом обработчике ID владельца зашит отдельно, а не берётся из `ADMIN_ID`. |
