# Команды и обращения ExpertBot

Справочник относится к текущему коду, а не подтверждает настройки конкретного
сервера. В группах доступ должен быть одобрен владельцем бота; доступность
функций зависит от `/panel`, прав Telegram, состояния MongoDB и провайдеров.
[README](README.md) описывает хранение истории, квоты и развёртывание.

Telegram-меню показывает только часть команд: его списки по ЛС, ЛС владельца и
группам находятся в [bot_commands.py](bot_commands.py). Команда может работать,
даже если её нет в меню. Telegram не принимает кириллицу в `setMyCommands`;
кириллические алиасы обрабатываются ботом как введённый текст, но интерфейс
клиента может не предлагать их как команды.

## Пользователям

| Команда или обращение | Назначение и условия |
| --- | --- |
| `/start`, `/help`, `/хелп`, `/хэлп`, `/справка`, `/экс помощь` | Краткая справка; `/help@имя_бота` также поддерживается. Для Штаба используется отдельная глубокая ссылка `/start alcbase`, которую выдаёт `/base` в группе. |
| `/support` | Связь с владельцем. |
| `Экс, вопрос`, `Эксперт, вопрос` | Диалог, поиск, погода, музыка, рисунки, игры и другие действия; запрос можно отправить текстом, голосовым или кружком. Для голосовых нужен модуль «Голосовые». |
| Ответ на сообщение самого бота | Текст, голосовое или кружок могут продолжить разговор без слова «Экс»; голосовое/кружок сначала распознаются. Ответ на чужое сообщение сам по себе не является обращением. |
| Фото с подписью `Экс, что на фото?` или ответ на фото с вопросом `Экс, ...` | Прямое распознавание фото. При ошибке бот сообщает, что не смог его рассмотреть, а не придумывает содержание. |
| `/bender вопрос`, `Экс, кружок вопрос` | Прямой запрос видеокружка в группе при включённых «Кружках Бендера» и настроенной студии. Текст запроса можно не указывать. |
| `/img запрос`, `/pic запрос`, `/рис запрос` | Генерация изображения. Две бесплатные успешные отправки в день на пользователя и чат, затем 250 игровых очков; день по МСК. Нужен модуль «Картинки» и доступный провайдер. |
| `/song название` | Поиск музыки и выбор трека. Нужен модуль «Музыка». |
| `/voice`, `/voice on`, `/voice off` | Статус и управление **публикацией** расшифровок. В группе статус доступен участникам, а переключение — администраторам и владельцу бота; в ЛС — пользователю. При `/voice off` модуль «Голосовые» продолжает фоновое распознавание и сохранение текста. Команда доступна при включённом модуле. |
| `/gossip [число]`, `/сплетни [число]`, `/вещай [число]`, `/выбор [число]` | Сводка по последним сообщениям чата: по умолчанию 50, диапазон 1–3000. Текстовые `сплетни`, `вещай`, `выбор` тоже поддерживаются. Один эксперт отвечает сразу; при нескольких показывается выбор. Сплетни независимы от панели «Отчёты (резерв)» и расписания суточного отчёта. |
| `/pole`, `/vis` (алиас `/виселица`) | Поле чудес и Виселица. |
| `/anachronism [ставка]`, `/анахронизм [ставка]`, `/ставка [ставка]` | Анахронизм; по умолчанию ставка 1000, необходимы очки в этом чате. |
| `/stop`, `/хватит` | Остановить активную партию Поля чудес или Виселицы. |
| `/topgame`, `/топигр`, `/очки` | Общий рейтинг игроков чата. |
| `/топполе [дни]` | Статистика Поля чудес, необязательный период в днях. |
| `/base`, `/база` | Штаб алхимии в ЛС; в группе бот выдаёт ссылку в ЛС. |
| `/pohod`, `/поход`, `/добыча` | Меню экспедиции алхимика. |
| `/грабить` | Рейд: нужен собранный и заряженный отряд. Ответом на игрока — нападение на него; без цели или при ответе боту — предложение PvE. |
| `Экс, шпора название` | Рецепт алхимии через Экса; после успешного запроса действует пятиминутная пауза. `/шпора` — отдельная команда только для владельца. |
| `/соцсправка`, `/ник имя`, `/пол м`, `/пол ж` | Справка Social RP и настройки профиля в чате. Само RP запускается текстом-ответом на другого участника, например `обнять`; модуль должен быть включён. |

Обычный ответ в группе может предлагать **⭕ Кружок / 🎙 Голос / 💬 Текст**
в зависимости от настроек панели. Выбирает автор запроса; выбор истекает через
3 минуты, затем бот пытается удалить меню. Если доступны только текстовые
ответы, меню не показывается. Включённый «Автоответ голосом» обходит выбор
для обычных обращений входящим голосовым, но не кружком. Специальные действия
(музыка, поиск, изображения, игры и т. д.) выполняются своим путём.

## Администраторам группы

| Команда | Назначение |
| --- | --- |
| `/panel`, `/панель` | Панель модулей непосредственно в группе; менять настройки могут администраторы группы или владелец бота. В личке владельца открывает общий пульт. |
| `/социал`, `/социал18` | Включить или выключить обычное / взрослое RP; права администратора группы проверяются обработчиком. |
| `/set_daily ЧЧ:ММ`, `/cron ЧЧ:ММ` | Задать ежедневный отчёт в группе по МСК. При выключенном модуле суточного отчёта используйте `/panel`: панель запрашивает время при включении. |
| `/stop_daily` | Отключить ежедневный отчёт группы. |
| `/vest` | Скрытый ручной отчёт за сутки для администратора группы; точное текстовое совпадение `/vest`. |

`/voice on/off` управляет общей настройкой публикации группы и требует прав
администратора или владельца бота. Отключение модуля «Голосовые» в панели
останавливает новые фоновые распознавания; уже запущенные могут завершиться.
Переключатель «Отчёты (резерв)» сохранён для совместимости со старыми
настройками и не управляет сплетнями. «Суточный отчёт» настраивается отдельно.
Обращение к Эксу с просьбой о сплетнях по-прежнему требует включённого «Эксперта»;
для голосового или кружка нужен также модуль «Голосовые».

## Владельцу бота и диагностике

Команды ниже не предназначены для обычных игроков. Если не указано иное,
обработчики проверяют `ADMIN_ID`; это не то же самое, что администратор группы.
Не передавайте секреты бота, ключи и содержимое `.env` в чат.

| Команда | Назначение / риск |
| --- | --- |
| `/panel` в личке | Пульт владельца: все действия доступны инлайн-кнопками, печатать команды не нужно. Экран «Справка → Все команды» показывает полный перечень резервных текстовых команд по разделам, чтобы их не приходилось искать в документации.  новости, настройки рисования и поиска, доступ и расписания групп, инструменты алхимии и проверки сервисов. С главной доступны быстрые входы в общую подборку, сценарии и выпуски. Каждый экран подписан путём вида «Пульт › Новости › Сценарии» и заканчивается кнопками «Обновить» и «Назад»/«Закрыть»; «Закрыть» удаляет экран, «Назад» возвращает на шаг выше без потери сохранённых данных. Открытие раздела или переход назад отменяет незаконченный текстовый ввод, чтобы следующее сообщение не попало в старую форму. Рисование и поиск переключаются для всех чатов. Статус показывает сохранённые данные, не проверяя работу сервисов в реальном времени. Опасные действия запрашивают подтверждение. Подробнее: [новостные черновики](news_prototype/OWNER_DRAFTS.md). |
| `/raid_test` | Только личка `ADMIN_ID` (проверяются отправитель, тип и ID чата): кнопка **Web App**, не обычная URL-ссылка, открывает публичный Pages-пробник Рейда внутри Telegram. Есть также «Пульт → Рейд · тест». Выход из незаконченной формы отменяет её ввод. Без рабочей игровой базы, серверного прогресса, CloudStorage и наград парка; сейвы локальные и могут отличаться от браузерных. Команда есть только в меню владельца. |
| `/news_prepare ССЫЛКА`, `/news_prepare_many ССЫЛКИ` | Только ЛС владельца: подготовить один сценарий или несколько по ссылкам; акцент задаётся следующей строкой. Расходует квоту Gemini. |
| `/news_discover` | Только ЛС владельца: найти новые публикации в настроенных источниках, без рендера. |
| `/news_pick`, `/news_drafts`, `/news_draft НОМЕР` | Только ЛС владельца: выбрать сюжет из найденного, список черновиков и карточка одного черновика. Карточка показывает стадию и, для `editor_failed`, безопасный код причины. |
| `/news_source НОМЕР`, `/news_edit`, `/news_nofocus`, `/news_noimage`, `/news_novideo` | Только ЛС владельца: прислать текст источника вместо недоступной статьи, изменить текст сценария, убрать увеличенные области кадра, картинку или видеофрагмент. Правки идут по версии сценария и не запускают рендер. |
| `/news_retry НОМЕР` | Только ЛС владельца: один ручной повтор подготовки сценария после ошибки редактора, по уже сохранённому источнику. Расходует квоту Gemini, не перечитывает статью и не запускает рендер. Причина ошибки видна в `/news_draft НОМЕР`. Код `refused` означает отказ фильтра безопасности Gemini на самом материале: повтор того же запроса даст тот же результат, поэтому нужен другой источник или кнопка «Прислать текст источника»; `empty_answer` — пустой ответ, повтор возможен, но не гарантирован. |
| `/news_approve НОМЕР ВЕРСИЯ`, `/news_trial`, `/news_trial_next`, `/news_trial_status` | Только ЛС владельца: подтвердить рендер конкретной версии, поставить следующий выпуск и проверить состояние постановки. Без подтверждения рендер не начинается. |
| `/news_program`, `/news_programs`, `/news_program_status`, `/news_program_approve` | Только ЛС владельца: собрать выпуск из готовых черновиков, список выпусков, состояние и подтверждение рендера выпуска. |
| `/news_daily_status`, `/news_collected` | Прежние команды состояния сбора и просмотра новостей, сохранены для совместимости. |
| `/news`, `/news_list`, `/news_ready`, `/news_digest`, `/news_digest_status` | Команды отдельного старого режима ручного приёма; доступны в панели «Новости → Настройки новостей → Ручные новости и старые дайджесты», только если этот режим уже включён. Он несовместим с режимом сценариев владельца; дополнительные включённые этапы могут автоматически обработать сохранённый материал. |
| `/chats` | Управление авторизацией чатов. |
| `/cron`, `/set_daily` в ЛС | Меню настройки суточных отчётов для групп. |
| `/image_probe` | Только ЛС владельца: реальные запросы к Cloudflare и OVHcloud; расходуются квоты, игровые попытки и очки не списываются. |
| `/search_image_probe [запрос]` | Только ЛС владельца: реальная проверка поиска с изображением, расходует квоту поиска. |
| `/regen_quests` | Принудительно перегенерировать квесты **всем игрокам**. |
| `/lore_help`, `/справкалор`; `/lore_edit`, `/lore_edit seed`, `/cancel_lore` | Справка и редактор наследия; `seed` обновляет стартовые наследия, `cancel_lore` отменяет ввод. Старая инициализация редактора удаляет запись `forge_legacy`; пульт предупреждает о ней до открытия редактора. |
| `/шпора [название]` | Точный рецепт; без названия полный список доступен только в ЛС владельца. |
| `/promo [s\|m\|l\|xl]`, `/промо [s\|m\|l\|xl]` | Выдать промо-пак алхимии игроку через reply; по умолчанию `s`. Изменяет инвентарь. |
| `/clear_inv` | Очистить инвентарь игрока через reply. **Необратимое изменение данных.** |
| `/alc_reset ID` | Удалить профиль алхимика по ID. **Необратимое изменение данных.** |
| `/промокод сумма` | Начислить или списать игровые очки через reply; также поддерживается поиск по имени. В этом старом обработчике ID владельца зашит отдельно, а не берётся из `ADMIN_ID`. Кнопочное изменение очков доступно владельцу из `ADMIN_ID`: выбирается группа и игрок из недавних записей или по ID, затем показывается подтверждение. |

При выдаче промопака, очистке инвентаря и удалении профиля через пульт можно выбрать игрока из 20 показанных или ввести числовой Telegram ID. Для промопака новому игроку дополнительно потребуется имя и подтверждение создания профиля. Профиль алхимии общий, не групповой. Для очков сначала выбирается конкретная группа, затем игрок из недавних записей или вводится его ID; новому игроку необходимо также указать имя. За одно действие допустимо начислить или списать до миллиона очков. Старые команды сохраняют свои прежние правила.

Дополнительный старый новостной режим не нужен для ежедневной подборки. Пульт не включает этот режим и его фоновые этапы. При добавлении материала и сборке дайджеста нужна отдельная проверка и подтверждение; в кнопочном выборе доступны до 100 последних готовых сюжетов, не более 20 на дайджест. При отключённом режиме этот раздел только показывает его состояние.

### Проверка Рейда в настоящем Telegram

После развёртывания этой версии **текущего бота** владелец отправляет `/raid_test`
в его личку (или `/panel` → «Рейд · тест»), затем нажимает **«Открыть Рейд · тест»**.
Нужна именно Web App-кнопка: обычная ссылка Pages открывает браузер и не доказывает
запуск Mini App. Номер «Ожидаемая сборка» у кнопки сверяется с номером в самой игре.
Приватен вход из бота, **не** публичная статическая страница; проверки ID на клиенте
не заменяют серверную авторизацию, которая в этом пробнике не используется.

Оболочка вызывает ready/expand, отключает вертикальное сворачивание при поддержке
клиента (7.7+), учитывает стабильную высоту и безопасные отступы. «Назад» закрывает
просмотр/редактор или открывает меню, но не отменяет обязательные награды; закрытие
живого забега запрашивает подтверждение при поддержке клиента. Статус SDK/старого
клиента/ошибки виден в пикере и меню; при сбое SDK локальная игра остаётся доступной,
но это **не** успешная проверка оболочки Telegram. Наш код не отправляет initData,
не запрашивает профиль, облако или рабочую игровую базу.

На телефоне проверить: цепочку пальцем без сворачивания, меню и прокрутку наград/
достижений, видимость «Подтвердить» в портретном и альбомном положении, «Назад»,
сворачивание и повторное открытие → **«Продолжить»**, неизменность выпавших карточек
и один ход врагов после завершения наград. Системная отмена незавершённого жеста
не должна делать ход. WebView может хранить сейвы отдельно от обычного браузера;
не очищать данные, ожидая переноса. Статическая публикация Pages и автотест SDK
**не подтверждают** обновление процесса бота или приёмку на физическом телефоне.
