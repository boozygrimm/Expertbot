# Start Here

Если сессия перезапустилась, открой этот файл первым. Он отражает текущее состояние большой фичи по `Модулю Вселенная`.

## Что уже внедрено

1. Новый старт алхимии.

- `/поход` по-прежнему является входом.
- `run_alchemy_intro()` теперь выдает расширенный стартовый набор.
- новичку заранее открываются стартовые рецепты: `lava`, `stone`, `steam`, `swamp`, `life`, `algae`, `moss`, `bacteria`.
- активация `base_crystal` больше не просто включает базу, а переводит игрока в этап создания первого микробиома.

2. Модуль мира и биомов.

- в профиле игрока добавлены поля `worlds`, `world_failures`, `world_tutorial`, `world_support_level`.
- есть мягкая миграция старых профилей через `get_or_create_player()`.
- legacy-игроки не теряют ничего: для них показывается аварийный статус “здания висят в воздухе и потрескивают”.

3. Первый и последующие биомы.

- первый биом всегда успешен.
- второй может `БАМММ`, но без штрафа.
- третий и дальше уже могут фейлиться с мягким возвратом.
- биомы собираются из стартовых трёх слотов:
  - `matter`
  - `medium`
  - `life`

4. Архетипы биомов.

- `stone + swamp + moss` -> опорный биом.
- `stone + steam + bacteria` -> промышленный биом.
- `lava + swamp + moss` -> добывающий биом.
- `lava + steam + bacteria` -> нестабильный биом.

5. Каркас мира.

- у мира есть `capacity` и отдельно `strain/stability`.
- биомы можно делать неограниченно, но мир начинает трещать.
- появился апгрейд каркаса через `world_support_level`.
- стройка блокируется, если мир перегружен.

6. Реальные бонусы для игрока.

- мир влияет на `/поход` через бонусы по локациям и редкости.
- мир влияет на пассивное производство в `collect_production_loot()`.
- окно `🌍` показывает:
  - биомы
  - роли
  - бонусы
  - каркас
  - перегруз

7. Фокусы зрелых биомов.

- после взросления мира открывается `focus` у нового биома.
- текущие фокусы:
  - `tech` через `electricity`
  - `lore` через `book`
  - `war` через `weapon`
  - `wild` через `forest`
- фокус тратит предмет при создании биома.
- фокус меняет бонусы, вместимость, нагрузку и требования поздней стройки.

8. Профильные требования стройки.

- поздние апгрейды зданий требуют не только ресурсы и вместимость.
- теперь часть апгрейдов требует:
  - роли биомов
  - зрелые фокусы биомов
- это реализовано в `handlers/alc_build.py`.

9. Достижения.

- добавлены ачивки за:
  - первый биом
  - несколько биомов
  - укрепление мира

10. Тесты.

- вся логика сопровождалась обновлением `tests/test_alchemy_logic.py`.
- сейчас целевой прогон:
  - `python -m unittest tests.test_alchemy_logic -q`
- на момент последнего состояния проходит `57` тестов.

## Что делать следующим

1. Не теряя интерес игрока, развивать миры в сторону “уникальных путей игры”, а не только в сторону ограничений.

- специальные события мира
- короткие текстовые врезки при походах и фейлах биомов
- ощущение, что мир “живой”

2. Добавить следующий слой прогрессии биомов.

- не только создавать новые биомы, но и улучшать существующие
- отдельные апгрейды конкретного биома
- возможно, локальные эффекты внутри мира

3. Открывать новые игровые ветки через мир.

- особые рецептурные цепочки под `tech/war/lore/wild`
- поздние боевые/производственные/лоровые модули
- возможно, отдельные редкие ресурсы по профилю мира

4. Не раздувать интерфейс.

- мир должен быть интересен игроку, а не превращаться в таблицу Excel
- в `🌍`-окне лучше 3-5 сильных решений, чем 15 мелких кнопок

## Что важно не сломать

- `/поход` должен оставаться понятной входной точкой.
- первый биом должен быть гарантированно комфортным.
- старые игроки не должны терять ресурсы или здания.
- стройка не должна стать душной слишком рано.
- любые новые ограничения должны сопровождаться заметной выгодой для игрока.
