# Тесты проекта

## Запуск тестов

```bash
# Все тесты
pytest

# С подробным выводом
pytest -v

# Только для social_rp
pytest tests/test_social_rp.py -v

# С покрытием кода
pytest --cov=handlers/social_rp tests/test_social_rp.py
```

## Результаты

**tests/test_social_rp.py**: 26/26 тестов проходят ✅

## Покрытие

Тесты покрывают критические функции модуля `social_rp.py`:
