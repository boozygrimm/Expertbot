## 2. Где мы сейчас (короткая сводка)

- Продукт: текстовая алхимия в боте **заменяется** мини-аппом; алхимия — первый
  аттракцион Луна-парка. В личке бота игры алхимии не будет.
- Прогресс игроков обнуляется, старая база — архив.
- Переход постепенный: лаборатория первой, остальное по готовности.
- Счётчики считаются формулой при открытии, фоновых задач не будет.
- Рейды и форт отложены; наследие и достижения — не решено.
- Активность в чате — только по кнопке «Поделиться».
- Идёт этап: **выработка концепта парка**. Открытые вопросы — раздел 4.

## 3. Что строим (в двух абзацах)

Луна-парк Бендера — одна игра внутри Telegram-бота, а не набор демо: игрок
входит из Telegram и продолжает тем же персонажем. Лаборатория алхимии —
первый аттракцион: игрок открывает рецепты, собирает коллекцию, берёт
контракты и проекты парка. Остальные павильоны добавляются позже, каждый со
своим аттракционом.

Цель дизайна — добровольный заход около пяти минут, без наказания за пропуск
дня: ничего не сгорает, накопленное считается при входе. Игра остаётся игрой, а
не бухгалтерией: игрок всегда видит цель, стоимость действия и что получит.

## 4. Принятые решения и открытые вопросы

**Принято (обсуждать заново не надо):**

| Тема | Решение |
|---|---|
| Судьба текстовой алхимии | заменяется мини-аппом, в личке её не будет |
| Прогресс игроков | обнуляется, старая база — архив |
| Переход | постепенно: сначала лаборатория |
| Старые команды | гасятся с заглушкой и кнопкой входа |
| Счётчики | формула при открытии, без фоновых задач |
| Рейды и форт | отложены |
| Активность в чате | только по кнопке «Поделиться» |
| Доступ | по существующим игрокам (есть в базе — входишь) |
| Хостинг | один адрес: страница и API в процессе бота |
| Первый показ | тот же бот, флаг + список ID |
| Аудитория | 10–30 человек |
| Лимит на крафт | нет |
| Память повторов | последние 100 запросов игрока |

**Открыто (нужно решение владельца):**

1. Наследие и достижения — аттракционы парка или функции бота?
2. Что игрок понимает о парке в первую минуту: есть сюжет/хозяин или это
   песочница с аттракционами?
3. Награды между аттракционами — общее мастерство на весь парк или у каждого
   павильона своё?
4. Почему возвращаться на следующий день, если ничего не сгорает и не набегает?
5. Нужны ли рейды вообще, или парк растёт в сторону открытий и коллекций?

## 5. Что уже сделано (материал, а не стройка)

- `lunapark-discovery.html` — playable-прототип лаборатории: котёл, коллекция,
  рецепты, история, анимации, контракты, тематические брифы, улики, мастерство,
  «Анализатор», проект парка на три элемента. Проверен на реальном телефоне,
  есть DOM-проверка в jsdom (`tools/lab_preview_check.js`).
- `lunapark-offline.html` — автономная демоверсия парка без сети.
- `miniapp_preview/` — исходники песочницы и 6 js-тестов (viewport в Chromium,
  Telegram-интеграция).
- `miniapp_backend/` — стенд: проверка Telegram `initData`, сессии, read-only
  проекция профиля, расчёт крафта, сторадж с версией и идемпотентностью.
  Покрыт 60 тестами (7 файлов тестов).
- `design/` — визуальные концепты парка и лаборатории.
- Документы-подробности: `LUNAPARK_CONCEPT.md` (парк и роль лаборатории),
  `LUNAPARK_FIRST_SESSION.md` (сценарий захода), `LUNAPARK_GAMEPLAY_MAP.md`
  (карта механик бота), `LUNAPARK_ROADMAP.md` (статусы, частично устарел),
  `LUNAPARK_STRATEGY.md` и `LUNAPARK_STAGE1_PLAN.md` (технические,
  **к исполнению не приняты, пока владелец не сменит режим**),
  `ALCHEMY_MINI_APP_PLAN.md` и `FREE_CAPACITY_OPTIONS.md` (оценки от 12.11).
